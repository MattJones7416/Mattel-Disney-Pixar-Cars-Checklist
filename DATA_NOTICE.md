# Catalogue data notice

Catalogue metadata is adapted from the [Disney•Pixar CARS Wiki Vehicle Database](https://dpcarswiki.com/Special:VehicleDatabase), which is available under the [Creative Commons Attribution-ShareAlike 4.0 International licence](https://creativecommons.org/licenses/by-sa/4.0/).

The generated catalogue keeps a source URL and licence marker on every entry. Changes made by this project include filtering to released Mattel Cars vehicle lines, excluding the Planes spin-off and non-die-cast product families, normalising identifiers, deriving collector-friendly groupings, and generating concise factual summaries.

Product images are not copied into the app or repository. Image fields point to the wiki's file redirect pages so each item retains a direct path back to its community-maintained source.
